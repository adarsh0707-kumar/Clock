# 🤝 Contributing to Clock

Thank you for taking the time to contribute to the **Clock** project! Contributions from the open-source community help improve and extend this project.

---

## 📜 Code of Conduct

Please maintain a respectful, welcoming, and collaborative environment. All discussions, issues, and pull requests should remain constructive and polite.

---

## 🛠️ How to Contribute

### 1. Reporting Bugs
- Search existing [Issues](https://github.com/adarsh0707-kumar/Clock/issues) to verify if the bug has already been reported.
- If not found, open a new issue detailing:
  - Steps to reproduce the bug.
  - Expected vs. actual behavior.
  - Your system environment (OS, compiler version).

### 2. Suggesting Features
- Open an issue describing the feature, its motivation, and potential implementation ideas.

### 3. Submitting Code Changes

Follow these steps to contribute code:

1. **Fork the Repository**
   Click the **Fork** button at the top right of the repository page.

2. **Clone Your Fork**
   ```bash
   git clone https://github.com/YOUR_USERNAME/Clock.git
   cd Clock
   ```

3. **Create a Feature Branch**
   ```bash
   git checkout -b feature/your-feature-name
   ```

4. **Make Your Modifications**
   - Write clean, well-documented C++ code following modern C++17 standards.
   - Keep header declarations in `include/` and source code in `src/`.
   - Verify that your code compiles cleanly without warnings.

5. **Commit Your Changes**
   ```bash
   git commit -m "feat: detailed description of feature or fix"
   ```

6. **Push to Your Fork**
   ```bash
   git push origin feature/your-feature-name
   ```

7. **Create a Pull Request (PR)**
   - Open a PR against the `main` branch of `adarsh0707-kumar/Clock`.
   - Provide a clear summary of the changes and reference any related issues.

---

Thank you for contributing! 🚀
